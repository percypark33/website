# Website workflow

Codex owns website and application changes. Claude owns the separate Square and Sheets integrations. Keep release surfaces explicit: website, TV menu, Square catalog and staff manuals each need their own verification.

1. Read the current project instructions and source notes before editing. Compare with the current deployed version and preserve unrelated work.
2. Scope changes to the requested files, names, links, prices and availability. Preserve approved artwork and ordering integrations.
3. Review the diff and run checks appropriate to the change, including mobile layout and affected ordering links.
4. Deploy only within the user's requested scope. Confirm the resolved production URL and visible changed content before reporting a release.

Private task briefs, shared AI handoffs, operational data and credentials belong in the private workspace. This public repository contains website material only.
